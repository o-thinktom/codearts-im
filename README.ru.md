# codearts-im

> CodeArts IM Gateway · Сопровождает ThinkTom

[简体中文](README.md) | [English](README.en.md) | **Русский** | [فارسی](README.fa.md) | [Türkçe](README.tr.md) | [Español](README.es.md)

IM-шлюз, который управляет локальным **Huawei Cloud CodeArts Agent** через QQ (поддержка WeChat / WeCom запланирована). Отправьте сообщение с телефона — Agent в настольной IDE выполнит задачу и вернёт результат.

## Возможности

- **Подключение по QR-коду**: создание/привязка бота через официальный коннектор Tencent — без ручного ввода AppID/AppSecret
- **Два режима чата**: личные сообщения и упоминания в группах (по умолчанию требуется @)
- **Управление сессиями**: отдельная сессия ядра на каждого собеседника, сохранение соответствий, автоматическое восстановление после перезапуска IDE
- **Надёжная доставка**: потоковые дельты, объединение многошаговых ответов, разбиение с учётом Markdown, ограничение `msg_seq` с деградацией
- **Участие человека**: подтверждения (`1` / `2`) и вопросы (`A/B/C`)
- **Только итоговый ответ**: цепочка рассуждений и системные подсказки фильтруются
- **Медиа**: загрузка и расшифровка входящих изображений/файлов, отправка файлов с деградацией до текстового пути
- **Контроль доступа**: режимы open / allowlist / disabled, коды сопряжения, отзыв, блокировка одного экземпляра
- **Проверяемость**: матрица совместимости ядра `npm run compat` для регрессии после обновлений

## Архитектура

    QQ Open Platform (WebSocket)
      ↕
    sidecar (единый бинарник Node SEA)
      ↕ локальный IPC (именованный канал + одноразовый токен)
    Расширение VS Code (VSIX)
      ↕ локальный HTTP + SSE
    CodeArts Agent Kernel (Session / Tools / Permission / Skills)

- Учётные данные и ядро остаются на локальной машине; sidecar не открывает публичный порт;
- `KernelPort` — единственная граница с ядром; транспорт QQ находится в `adapters/qq`;
- Расширение отвечает за жизненный цикл, привязку по QR, поиск порта ядра и расшифровку пароля.

## Установка

Требования: Windows x64, CodeArts Agent 26.11.x. Node.js **не требуется**.

    & "<каталог CodeArts>\bin\codearts-agent.cmd" --install-extension "<путь>\codearts-qqbot-cn-0.3.2.vsix"

Либо используйте «Установить из VSIX» в панели расширений и выполните «Developer: Reload Window».

## Быстрый старт

1. Запустите CodeArts Agent и проведите один диалог, чтобы ядро запустилось;
2. Палитра команд → «QQ Bot: 扫码绑定机器人» (привязка по QR);
3. Отсканируйте официальный QR-код в мобильном QQ и завершите создание/привязку на странице Tencent;
4. Учётные данные сохраняются в системном хранилище секретов, подключение перезапускается автоматически;
5. Отправьте боту личное сообщение.

Если сканирование недоступно, используйте «QQ Bot: 手动填写凭据» (ручной ввод).

## Безопасность и данные

- AppSecret и пароль ядра хранятся только в системном хранилище секретов или в памяти — не в конфигурации, репозитории и журналах;
- Пароль ядра читается из официального зашифрованного хранилища только для чтения, с ручным резервным вводом;
- Исходящие файлы проверяются по списку разрешённых путей `realpath` (рабочая область + медиа), до 20 МБ на файл;
- Журналы и диагностика скрывают секреты, токены и openid;
- В QQ отправляется только итоговый ответ; рассуждения и системные подсказки не передаются.

## Сборка

Среда разработки: Windows x64, Node.js ≥ 20.3, CodeArts Agent 26.11.x для интеграции.

    npm install
    npm run check            # правила слоёв / типы / модульные тесты
    npm run build:sidecar    # единый исполняемый файл Node SEA
    npm run package:vsix     # сборка расширения и упаковка VSIX

## Известные ограничения

- Артефакты только для Windows x64; для других платформ нужна нативная сборка;
- Жёсткая привязка к версиям CodeArts Agent/ядра — после обновления требуется регрессия;
- Окно пассивного ответа QQ — около 5 минут и максимум 5 ответов на сообщение;
- Группы по умолчанию в allowlist; `open` — только для локальной интеграции;
- Подтверждения и вопросы текстовые (цифры/буквы); карточки-кнопки пока не реализованы.

## Диагностика

Откройте канал вывода «CodeArts QQ Bot» и ориентируйтесь по маркерам:

| Журнал | Значение |
|---|---|
| `sidecar binary not found` | В VSIX нет `bin/`; переустановите |
| `ipc bridge connected` | Расширение и sidecar соединены |
| `已从码道加密存储获取内核口令` | Пароль ядра получен автоматически |
| `sidecar running` / `qq bot ready` | Сервис и QQ готовы |
| `qq message received` | Входящее сообщение QQ получено |
| `inbound accepted` / `kernel prompt sending` | Передано в ядро |
| `reply sending` / `outbound send failed` | Результат отправки и причина ошибки |
