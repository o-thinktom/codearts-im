# CodeArts IM

[简体中文](README.md) | [English](README.en.md) | [Русский](README.ru.md) | **فارسی** | [Türkçe](README.tr.md) | [Español](README.es.md)

دروازه‌ای برای پیام‌رسان که **Huawei Cloud CodeArts Agent** را روی رایانه محلی از طریق QQ هدایت می‌کند (پشتیبانی از WeChat و WeCom در نقشه راه است). یک پیام از گوشی بفرستید؛ Agent در IDE دسکتاپ وظیفه را اجرا و نتیجه را برمی‌گرداند.

## ویژگی‌ها

- **اتصال با اسکن QR**: ساخت/اتصال ربات با کانکتور رسمی Tencent، بدون ورود دستی AppID/AppSecret
- **دو حالت گفتگو**: پیام خصوصی و اشاره در گروه (به‌طور پیش‌فرض نیاز به @)
- **مدیریت نشست**: یک نشست هسته برای هر مخاطب، ذخیره نگاشت‌ها و بازیابی خودکار پس از راه‌اندازی مجدد IDE
- **تحویل مطمئن**: دلتاهای جریانی، ادغام پاسخ‌های چندمرحله‌ای، تقسیم آگاه از Markdown، محدودسازی `msg_seq` با تنزل
- **تعامل انسانی**: تأییدها (`1` / `2`) و پرسش‌ها (`A/B/C`)
- **فقط پاسخ نهایی**: زنجیره استدلال و پیام‌های سیستمی فیلتر می‌شوند
- **رسانه**: دریافت و رمزگشایی تصویر/فایل ورودی، ارسال فایل با تنزل به مسیر متنی
- **کنترل دسترسی**: حالت‌های open / allowlist / disabled، کد جفت‌شدن، لغو دسترسی، قفل تک‌نمونه‌ای
- **قابل بررسی**: ماتریس سازگاری هسته با `npm run compat` برای رگرسیون پس از به‌روزرسانی

## معماری

    QQ Open Platform (WebSocket)
      ↕
    sidecar (یک باینری Node SEA)
      ↕ IPC محلی (named pipe + توکن یک‌بارمصرف)
    افزونه VS Code (VSIX)
      ↕ HTTP محلی + SSE
    CodeArts Agent Kernel (Session / Tools / Permission / Skills)

- اعتبارنامه‌ها و هسته فقط روی دستگاه محلی می‌مانند؛ sidecar پورت عمومی باز نمی‌کند؛
- `KernelPort` تنها مرز اتصال به هسته است و انتقال QQ در `adapters/qq` قرار دارد؛
- افزونه چرخه عمر، اتصال با QR، کشف پورت هسته و رمزگشایی گذرواژه را بر عهده دارد.

## سازگاری

| مورد | پشتیبانی | توضیح |
|---|---|---|
| سیستم‌عامل | Windows 10 1809+ / Windows 11 (x64) | بسته منتشرشده win32-x64 است؛ macOS/Linux نیازمند ساخت روی همان پلتفرم است |
| CodeArts Agent | ≥ 26.11.100 | آزمایش‌شده روی 26.11.x |
| Agent Kernel | 126.11.x | آزمایش‌شده روی `126.11.2-20261117200150` |
| VS Code API | `^1.109.0` | فقط APIهای پایدار |
| QQ Open Platform | Bot WebSocket API v2 | ربات آزمایشی یا رسمی |
| Node.js (فقط توسعه) | ≥ 20.3 | کاربر نهایی نیازی ندارد؛ runtime در sidecar تعبیه شده است |

بررسی سازگاری:

    npm run compat                    # فقط خواندن + ساخت/حذف نشست
    npm run compat -- --with-prompt   # یک استنتاج واقعی اضافه می‌کند (مصرف کم سهمیه)

## نسخه

- نسخه فعلی: **0.3.2** (نسخه‌بندی معنایی؛ در شاخه 0.x رابط‌ها ممکن است تغییر کنند)
- مبنای سازگاری: CodeArts Agent 26.11.100 / Kernel 126.11.2
- سیاست به‌روزرسانی: پس از هر به‌روزرسانی IDE یا هسته، ابتدا ماتریس سازگاری را اجرا کنید
- تاریخچه تغییرات: تاریخچه commitها و اسناد طراحی در `output/`

## نصب

پیش‌نیاز: Windows x64 و CodeArts Agent 26.11.x. نصب Node.js **لازم نیست**.

    & "<مسیر نصب CodeArts>\bin\codearts-agent.cmd" --install-extension "<مسیر>\codearts-qqbot-cn-0.3.2.vsix"

همچنین می‌توانید از «Install from VSIX» در نمای افزونه‌ها استفاده کرده و سپس «Developer: Reload Window» را اجرا کنید.

## شروع سریع

1. CodeArts Agent را اجرا و یک گفتگو انجام دهید تا هسته فعال شود؛
2. Command Palette → «QQ Bot: 扫码绑定机器人» (اتصال با QR)؛
3. کد QR رسمی را با QQ موبایل اسکن و ساخت/اتصال را در صفحه Tencent کامل کنید؛
4. اعتبارنامه در مخزن امن سیستم ذخیره و اتصال خودکار راه‌اندازی مجدد می‌شود؛
5. به ربات پیام خصوصی بفرستید.

در صورت نبود امکان اسکن، از «QQ Bot: 手动填写凭据» (ورود دستی) استفاده کنید.

## امنیت و داده‌ها

- AppSecret و گذرواژه هسته فقط در مخزن امن سیستم یا حافظه نگه‌داری می‌شوند — نه در پیکربندی، مخزن یا گزارش‌ها؛
- گذرواژه هسته فقط‌خواندنی از مخزن رمزنگاری‌شده رسمی خوانده می‌شود و در صورت خطا به ورود دستی برمی‌گردد؛
- فایل‌های خروجی با فهرست مسیرهای مجاز `realpath` (workspace + media) بررسی می‌شوند؛ حداکثر ۲۰ مگابایت برای هر فایل؛
- گزارش‌ها و بسته تشخیصی، رمزها، توکن‌ها و openid را پوشانده می‌کنند؛
- فقط پاسخ نهایی ارسال می‌شود؛ استدلال و پیام‌های سیستمی به QQ نمی‌رسند.

## ساخت

محیط توسعه: Windows x64، Node.js ≥ 20.3 و CodeArts Agent 26.11.x برای یکپارچه‌سازی.

    npm install
    npm run check            # قواعد لایه‌ها / نوع‌ها / تست واحد
    npm run build:sidecar    # فایل اجرایی تک‌بدنه Node SEA
    npm run package:vsix     # ساخت افزونه و بسته VSIX

## محدودیت‌های شناخته‌شده

- فقط بسته Windows x64؛ سایر پلتفرم‌ها نیازمند ساخت بومی هستند؛
- وابستگی شدید به نسخه CodeArts Agent/هسته — پس از به‌روزرسانی، رگرسیون لازم است؛
- پنجره پاسخ غیرفعال QQ حدود ۵ دقیقه و حداکثر ۵ پاسخ برای هر پیام؛
- گروه‌ها به‌طور پیش‌فرض allowlist هستند؛ `open` فقط برای یکپارچه‌سازی محلی است؛
- تأیید و پرسش متنی است (عدد/حرف)؛ کارت‌های دکمه‌ای هنوز پیاده‌سازی نشده‌اند.

## عیب‌یابی

کانال خروجی «CodeArts QQ Bot» را باز کنید و نشانه‌های گزارش را بررسی کنید:

| گزارش | معنا |
|---|---|
| `sidecar binary not found` | بسته VSIX فاقد `bin/` است؛ دوباره نصب کنید |
| `ipc bridge connected` | افزونه و sidecar متصل شدند |
| `已从码道加密存储获取内核口令` | گذرواژه هسته خودکار دریافت شد |
| `sidecar running` / `qq bot ready` | سرویس و اتصال QQ آماده است |
| `qq message received` | پیام ورودی QQ دریافت شد |
| `inbound accepted` / `kernel prompt sending` | به هسته ارسال شد |
| `reply sending` / `outbound send failed` | نتیجه ارسال و علت خطا |
